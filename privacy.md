# Privacy Policy — Teo's Stylist Agent

Last updated: October 5, 2026

Teo's Stylist Agent is a personal, single-user application operated by Teodora Cioca.
It is not offered to the public.

**What data it accesses:** with my authorization via Pinterest OAuth, the app reads my own
boards and Pins (read-only). It does not access other users' data and does not create,
edit or delete any Pinterest content.

**What it stores:** Pin IDs, image URLs and style attributes derived from my own Pins,
stored on my personal computer. Access tokens are stored encrypted. No data is sold,
shared with third parties, or used for advertising.

**Third-party processing:** images of my own Pins may be sent to an AI model provider
(Google Gemini API) to generate style descriptions.

**Deletion:** I can revoke access at any time in Pinterest settings; all stored data is
deleted when access is revoked or the project ends.
